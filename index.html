01

Алгоритм және программалау туралы түсінік

Оқу мақсаты: алгоритмнің не екенін түсіндіру және күнделікті әрекетке алгоритм құру.

Алгоритм — белгілі бір мақсатқа жету үшін ретімен орындалатын нақты әрекеттер тізбегі. Мысалы, таңертең мектепке дайындалудың да өз реті бар. Программа — компьютер орындай алатын командалар жиынтығы.

Алгоритмнің қасиеттері

Реттілік: әрекеттер дұрыс тәртіппен орындалады.

Түсініктілік: әр қадам анық беріледі.

Нәтижелілік: соңында көзделген мақсатқа жетеміз.

Күнделікті мысал

Шай дайындау: 1) шәйнекке су құю; 2) суды қайнату; 3) кесеге шай салу; 4) ыстық су құю; 5) шайды демдеу.

Тапсырма

«Мектепке сөмке жинау» әрекетіне 4–5 қадамнан тұратын алгоритм жаз. Қадамдардың ретін тексер.

1. Ертеңгі сабақ кестесін қарау. 2. Қажетті кітап пен дәптерді алу. 3. Қаламсауытты салу. 4. Сөмкені тексеру. 5. Сөмкені есікке қою.
02

Python тілі және программалау ортасы

Оқу мақсаты: Python ортасын іске қосып, жаңа программа файлын ашу.

Python — адамға түсінікті командалар арқылы компьютерге нұсқау беретін программалау тілі. Кодты жазу және іске қосу үшін программалау ортасы қолданылады. Мысалы, Thonny ортасында жаңа файл ашып, программаны орындауға болады.

Thonny-де жұмыс реті

1. Thonny программасын іске қос.

2. File → New арқылы жаңа файл аш.

3. Кодты редакторға жаз.

4. Run → Run current script пәрменін таңда.

Файлды сақтау

File → Save As таңда. Файл атауын salem.py сияқты латын әріптерімен жаз. Python файлдарының соңында .py кеңейтімі болады.

Мысал · salem.py
# Бірінші команда
print("Мен Python үйреніп жүрмін!")
Мен Python үйреніп жүрмін!

Тапсырма

Программалау ортасында жаңа файл ашып, өз есіміңді экранға шығаратын программа жаз. Файлды menin_programmam.py деп сақта.

03

Алғашқы программа. print() командасы

Оқу мақсаты: print() командасын қолданып, мәтін мен сандарды экранға шығару.

print() — ақпаратты экранға шығаратын команда. Мәтін тырнақшаның ішінде жазылады. Сандарды тырнақшасыз да шығаруға болады.

Код мысалы · print_demo.py
print("Сәлеметсің бе!")
print(2026)
print(5 + 3)
Сәлеметсің бе! 2026 8

Есте сақта

Команданың атауы кіші әріппен жазылады. Жақшаны ашып-жабуды ұмытпа. Мәтінді тырнақшаға ал: print("мәтін").

Тапсырма

Үш жол шығаратын код жаз: өз есімің, сыныбың және 7 + 6 өрнегінің нәтижесі.

print("Айдана")
print("6-сынып")
print(7 + 6)
04

Мәтінді экранға шығару және комментарий жазу

Оқу мақсаты: мәтінді форматтап шығару және программаға түсіндірме жазу.

Бір print() командасымен бірнеше мәнді үтір арқылы шығаруға болады. Әр мәннің арасына бос орын қойылады. Комментарий — программадағы түсіндірме. Python оны орындамайды; комментарий # таңбасынан басталады.

Мысал · мәтін және комментарий
# Оқушы туралы мәлімет
print("Аты:", "Нұржан")
print("Сүйікті саны:", 8)
Аты: Нұржан Сүйікті саны: 8

Тапсырма

Өзің туралы екі мәліметті экранға шығар. Бірінші жолдың алдына сол жолдың не туралы екенін түсіндіретін комментарий жаз.

# Мен туралы
print("Атым:", "Дана")
print("Жасым:", 12)
05

Айнымалылар және мәндерді сақтау

Оқу мақсаты: айнымалы құрып, оған мән мен сәйкес атау беру.

Айнымалы — программа жұмыс істеп тұрған кезде мән сақтайтын атаулы орын. Айнымалыға мән меншіктеу үшін = белгісі қолданылады. Мысалы, аты = "Әли".

Мысал · айнымалыны қолдану
аты = "Әли"
сынып = 6
ұпай = 9

print("Оқушы:", аты)
print("Сыныбы:", сынып)
print("Ұпайы:", ұпай)
Оқушы: Әли Сыныбы: 6 Ұпайы: 9

Жақсы атау қандай болады?

Атауы мәнін түсіндірсін: жас, аты, баға. Бос орын қолданба: менің атым орнына menin_atym деп жаз.

Мәнді жаңарту

Айнымалыға кейін басқа мән беруге болады. Мысалы: ұпай = 7, кейін ұпай = 10.

Тапсырма

қала және ел деген екі айнымалы құрып, олардың мәндерін бір сөйлем етіп экранға шығар.

қала = "Түркістан"
ел = "Қазақстан"
print(қала, "қаласы", ел)
Мәтінді тырнақшамен мұқият жап. Мысалы, екі бөлікке бөлуге болады: print(қала, "қаласы", ел).
06

Мәліметтер типтері: бүтін сан, бөлшек сан, мәтін

Оқу мақсаты: негізгі мәліметтер типтерін ажыратып, программада қолдану.

Айнымалыда сақталған деректің типі оның қандай мән екенін көрсетеді. Бүтін сан — int, бөлшек сан — float, мәтін — str. Python-да типті type() командасымен тексеруге болады.

Мысал · дерек типтері
жас = 12          # int — бүтін сан
бой = 1.48       # float — бөлшек сан
аты = "Меруерт"  # str — мәтін

print(type(жас))
print(type(бой))
print(type(аты))
<class 'int'> <class 'float'> <class 'str'>
Жылдам тексеру: 3.14 қай типке жатады?

Тапсырма

кітап_саны, баға, кітап_аты айнымалыларына сәйкес мән бер. Әрқайсысының типін type() арқылы көрсет.

07

input() командасы арқылы мәлімет енгізу

Оқу мақсаты: input() арқылы енгізілген деректі айнымалыға сақтау.

input() командасы пайдаланушыдан мәлімет енгізуді сұрайды. Енгізілген жауап мәтін түрінде сақталады. Егер санмен есептеу керек болса, оны int() арқылы бүтін санға айналдырамыз.

Мысал · есімді енгізу
аты = input("Атың кім? ")
print("Сәлем,", аты)
Атың кім? Айша Сәлем, Айша
Мысал · екі санды қосу
бірінші = int(input("Бірінші сан: "))
екінші = int(input("Екінші сан: "))
қосынды = бірінші + екінші
print("Қосынды:", қосынды)
Бірінші сан: 4 Екінші сан: 7 Қосынды: 11

Неге int() керек?

input() жауабы бастапқыда мәтін болады. int() оны бүтін санға айналдырады, сонда қосу, азайту сияқты амалдарды орындауға болады.

Тапсырма

Пайдаланушыдан туған жылын сұрап, «Сенің туған жылың: …» деп шығаратын программа құрастыр.

жыл = input("Туған жылыңды енгіз: ")
print("Сенің туған жылың:", жыл)
08

I тоқсан бойынша практикалық жұмыс

Оқу мақсаты: енгізу, шығару және айнымалыны қолданып, қарапайым есептің программасын құру.

Практикалық жұмыс: «Оқушы туралы мәлімет». Пайдаланушыдан аты мен жасын сұрап, бес жылдан кейінгі жасын есептеп, нәтижені экранға шығарамын.

Толық программа · okushy.py
# Оқушыдан мәлімет енгізу
аты = input("Атыңды енгіз: ")
жас = int(input("Жасыңды енгіз: "))

келешек_жас = жас + 5

print("Сәлем,", аты)
print("Қазір сен", жас, "жастасың.")
print("Бес жылдан кейін сен", келешек_жас, "жаста боласың.")
Атыңды енгіз: Айша Жасыңды енгіз: 12 Сәлем, Айша Қазір сен 12 жастасың. Бес жылдан кейін сен 17 жаста боласың.

Орындау реті

1. Кодты жаңа файлға көшіріп жаз.

2. Файлды сақтап, іске қос.

3. Атың мен жасыңды енгіз.

4. Нәтижені тексер.

Бағалау критерийі

• input() көмегімен екі дерек енгізеді.

• Жасты int() арқылы санға айналдырады.

• Айнымалыға есептеу нәтижесін сақтайды.

• Нәтижені print() арқылы шығарады.

Өзіңді тексер: жас енгізіліп, айнымалыда сан ретінде сақталуы үшін қай жазылым дұрыс?

ЕСЕП

Практикалық бөлім · 5 есеп

Орындау шарты: есептерді Python ортасында орындаңыз. Қажет жерінде input(), int(), айнымалылар және print() қолданыңыз.

1-есеп. Сәлемдесу

Пайдаланушыдан аты мен сыныбын сұрап, «Сәлем, [аты]! Сен [сынып]-сыныпта оқисың.» деген хабарлама шығаратын программа құрыңыз.

Мысал енгізу: Аружан, 6 Күтілетін нәтиже: Сәлем, Аружан! Сен 6-сыныпта оқисың.

2-есеп. Екі санның қосындысы

Екі бүтін сан енгізіп, олардың қосындысын экранға шығарыңыз. Енгізілген мәндерді бүтін санға айналдырыңыз.

Мысал енгізу: 12 және 8 Күтілетін нәтиже: Қосынды: 20

3-есеп. Тік төртбұрыш

Тік төртбұрыштың ұзындығы мен енін енгізіңіз. Оның ауданын ұзындығы × ені, периметрін 2 × (ұзындығы + ені) формулаларымен есептеп, экранға шығарыңыз.

Мысал енгізу: ұзындығы 7, ені 4 Күтілетін нәтиже: Ауданы: 28; периметрі: 22

4-есеп. Жас есебі

Пайдаланушының қазіргі жасын сұраңыз. Бес жылдан кейінгі жасын есептеп, екі мәнді де түсінікті мәтінмен көрсетіңіз.

Мысал енгізу: 11 Күтілетін нәтиже: Қазір: 11 жас. Бес жылдан кейін: 16 жас.

5-есеп. Дәптер сатып алу

Бір дәптердің бағасы мен сатып алынатын дәптер санын сұраңыз. Жалпы құнын есептеп, заттың атауы мен сомасын көрсетіңіз.

Мысал енгізу: бағасы 80 теңге, саны 5 Күтілетін нәтиже: 5 дәптердің жалпы құны: 400 теңге.
